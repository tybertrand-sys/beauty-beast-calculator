Short summary:
This is an offline Progressive Web App (PWA) starter for the Beauty & Beast Wellness Dosage Calculator.
It currently includes:
Home screen with:
Today
Calculate
My Vials
History
Dark/light mode
Offline support (service worker)
Local storage (your data stays on the device)
Calculation engine foundation
Engine versioning (v1.0.0)
Household data structure for:
Shared vials
Beast profile
Beauty profile
Regimens
History
Events
The package contains six files:
index.html – app interface
app.js – application logic
styles.css – styling
manifest.webmanifest – installable app settings
sw.js – offline functionality
icon.svg – app icon
It's a foundation, not the finished product we've been designing. It doesn't yet include all the features we've agreed on, such as the complete smart calculator, regimen automation, shared inventory workflow, equivalency tools, transaction system, or full "Show My Math" experience. Those still need to be built.
