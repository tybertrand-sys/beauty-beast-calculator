# Beauty & Beast Wellness Android APK

This is the complete Android wrapper project for the private Version 2.1 app.

## Build with GitHub Actions
1. Upload the contents of this project to a GitHub repository.
2. Open **Actions**.
3. Select **Build Android APK**.
4. Tap **Run workflow**.
5. Open the completed workflow run.
6. Download **Beauty-Beast-Wellness-v2.1-debug**.
7. Extract the artifact and install `app-debug.apk`.

The debug APK is intended for private testing. A public release needs a private signing key.
