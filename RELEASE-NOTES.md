# Beauty & Beast Wellness — Private Version 2.0

## Release status
This is the first consolidated release-candidate build.

## Major capabilities
- Dose, reconstitution, blend, and unit conversion calculators
- Show My Math
- Beast and Beauty profiles
- Preloaded personal protocol records
- Protocol phase selection and calculator loading
- Vial inventory, remaining-dose estimates, and low-supply status
- Reminders, schedule building, snooze, and editing
- Recorded activity and inventory deduction
- Undo last recorded dose
- Dashboard, history, CSV exports, and printable protocol summary
- Offline PWA support and GitHub Pages deployment
- Backup, restore, safety snapshots, and protocol import/export
- Built-in diagnostics, self-test, and release check

## Important PWA limitation
Reliable notifications while the app is fully closed are restricted by browser and Android behavior. The current PWA checks alerts while active. Full background scheduling remains an APK-stage enhancement.
